📚 Les notions étudiées
🖥️ Adresse IP

Une adresse IP permet d'identifier un appareil sur un réseau.

Exemple :

192.168.1.25

Une adresse IP peut être utilisée pour permettre à différents appareils de communiquer entre eux.

🔗 Adresse MAC

Une adresse MAC est une adresse associée à l'interface réseau d'un appareil.

Elle permet notamment d'identifier une interface réseau sur un réseau local.

🌍 DNS

Le DNS permet de traduire un nom de domaine en adresse IP.

Par exemple :

google.com → adresse IP du serveur correspondant.

Cela évite d'avoir à retenir des adresses IP pour accéder aux sites Internet.

📡 DHCP

Le DHCP permet d'attribuer automatiquement une configuration réseau à un appareil.

Par exemple, lorsqu'un ordinateur se connecte à une box Internet, celle-ci peut lui attribuer automatiquement une adresse IP.

📶 Ping

La commande ping permet de tester si un appareil peut communiquer avec une autre machine sur un réseau.

Exemple :

ping 8.8.8.8

Cela permet notamment de vérifier si une connexion réseau fonctionne.
